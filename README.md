\# Node.js DevOps Demo Application



A simple Node.js application created as part of a DevOps internship project, demonstrating application development, Git version control, Docker containerization, and CI/CD automation using GitHub Actions.



\## 🛠️ Technologies Used



\- Node.js

\- Docker

\- Git

\- GitHub

\- GitHub Actions

\- Docker Hub
